# Model Registry Policy

Every detector used in hosted production must be registered with:

- model name,
- version or checkpoint hash,
- modality,
- source URI,
- license,
- production approval status,
- validation datasets,
- AUC, EER, F1, calibration error, latency, and false positive rate.

Non-commercial checkpoints can be used for local research and benchmarking only. They must not power paid or public hosted inference.
