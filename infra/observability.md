# Observability

Track these production signals from day one:

- API latency by route and status code.
- Upload size and rejection counts.
- Redis queue depth for `orchestration` and `ml`.
- GPU worker latency by juror and model version.
- Visual/acoustic/context juror error rates.
- Final verdict distribution by organization.
- Cost per case from LLM, transcription, search, storage, and GPU runtime.
- Free-tier quota pressure and rejected analyses.
